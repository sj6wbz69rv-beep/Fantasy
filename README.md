# SMOY

**SMOY** is an original mobile open-world MMORPG project for iOS.

The project retains its established design and first playable slice:
- Realistic third-person high-fantasy / science-fiction world
- Neo-City as the opening social hub
- The first story quest: **The Missing Signal**
- Touch movement and mobile combat foundations
- A Unity 6.3 LTS project baseline

The public-facing game title is now **SMOY**. Existing internal Unity class names and the current GitHub repository name may continue to use the legacy FANTASY identifier until those technical identifiers are safely migrated.

## Build status

This repository is still a development project, not a compiled or tested iOS game. See [Project Status](Documentation/PROJECT_STATUS.md) for the current validation gates.
